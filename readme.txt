== Description ==

Shipbubble is a post purhcase platform that enables retailers to conveniently delight their customers with multiple shipping options and a branded tracking experience thereby increasing conversion rates.

[youtube https://www.youtube.com/watch?v=eGxMxB0QbXc]

== Features ==

* Access pre-negotiated courier rates across our 20+ partners.
* Build customer trust by offering transparency at rates at checkout as customers can see delivery times as well as prices.
* Access to both international and domestic carrier options.
* Ship to over 220 countries world wide.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/shipbubble` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress
1. Generate and copy your production api key from your shipbubble dashboard
1. Validate your API key.
1. Once your API key is valid, you will be provided with a link to configure your shipbubble woocommerce settings
1. Once your shipbubble woocommerce settings have been saved, you now have rates at checkout available to your customers
