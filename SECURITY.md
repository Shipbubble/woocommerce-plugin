# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.10.x  | Yes                |
| < 2.10  | No                 |

## Reporting a Vulnerability

We take the security of Shipbubble and our users seriously. If you discover a security vulnerability, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please send an email to **security@shipbubble.com** with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

## Response Timeline

- **Acknowledgment**: Within 48 hours of receiving the report
- **Assessment**: Within 5 business days
- **Fix/Patch**: Depending on severity, typically within 7-14 business days

## Security Best Practices for Users

- Always keep the plugin updated to the latest version.
- Use strong, unique API keys and do not share them publicly.
- Use live mode only in production environments; use sandbox mode for testing.
- Ensure your WordPress installation, PHP version, and WooCommerce are up to date.
- Restrict access to the WordPress admin panel to authorized users only.

## Scope

This policy applies to the Shipbubble WordPress/WooCommerce plugin. For security concerns related to the Shipbubble API or platform, please contact us at **security@shipbubble.com**.
